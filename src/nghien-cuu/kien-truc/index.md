# Top Github project

Các bài nghiên cứu về các chủ để hot trên github

## Danh mục Nghiên cứu

- [EDD và kiến trúc đánh giá agent với Langfuse + DeepEval](./edd-langfuse-deepeval/) — Eval-Driven Development, công cụ GitHub, kiến trúc CI/runtime, phản biện và nguồn đọc trực tiếp.
- [Hướng dẫn Sử dụng & Vận hành Langfuse Self-Hosted (v4)](./langfuse-self-hosted/) — Cẩm nang triển khai Docker Compose, cấu hình API Keys, tích hợp SDK (Python/TS), thu thập Traces, quản lý Prompt và vận hành thực tế.
- [Bộ công cụ đánh giá LangGraph: Langfuse, DeepEval và AgentCore](./langgraph-eval-stack-langfuse-deepeval-agentcore/) — Tổng thuật eval stack cho agent LangGraph: từ Langfuse đến AWS AgentCore, phân chia chất lượng hội thoại / điều phối / truy xuất.
- [Theo dõi và chấm điểm pipeline RAG với Langfuse và DeepEval](./tracing-scoring-rag-langfuse-deepeval/) — Tổng thuật mẫu trace + score cho pipeline RAG mà không làm chậm, kết hợp Langfuse và DeepEval.
- [BIAN: Chuỗi Giá trị từ OKR đến CNTT](./bian-okr-to-it-value-chain/) — Kiến trúc chuỗi giá trị từ Objective/KR nghiệp vụ, đánh giá tác động kiến trúc (Enterprise Architecture) đến nhu cầu CNTT (BIAN Service Landscape V14).
- [Nền tảng Tri thức Cá nhân WeKnora](./weknora-personal-knowledge-platform/) — Nền tảng quản trị tri thức cá nhân chạy local với RAG, ReAct Agent và Auto-Wiki. Gồm [Kiến trúc triển khai](./weknora-personal-knowledge-platform/), [Hướng dẫn sử dụng](./weknora-personal-knowledge-platform/huong-dan-su-dung) và [Đánh giá Kiến trúc & C4 Model](./weknora-personal-knowledge-platform/danh-gia-kien-truc).
