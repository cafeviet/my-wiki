# Cách hoạt động

AgentCore Runtime (môi trường chạy) cung cấp hai loại compute để lưu trữ (host) agent của bạn: **microVMs** và **Instances**. Các chủ đề sau mô tả cách hoạt động của từng loại compute để bạn có thể chọn loại phù hợp với khối lượng công việc của mình. Để so sánh song song, xem [Compare compute types](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-instances-how-it-works.html#runtime-instances-compute-comparison).
