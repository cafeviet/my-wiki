# Bắt đầu với AgentCore Runtime

Bạn có thể dùng các hướng dẫn (tutorial) sau để bắt đầu với Amazon Bedrock AgentCore Runtime (môi trường chạy).

[AgentCore CLI](https://github.com/aws/agentcore-cli) là một giao diện dòng lệnh (Command Line Interface, CLI) giúp đơn giản hóa việc thiết lập hạ tầng để đóng gói container và triển khai một agent (tác tử AI) lên AgentCore Runtime.

- [Get started without the AgentCore CLI](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/getting-started-custom.html)

- [Get started with Instances](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-instances-getting-started.html)

- [Get started with Amazon Bedrock AgentCore Runtime direct code deployment](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-get-started-code-deploy.html)

- [Get started with bidirectional streaming using WebSocket](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-get-started-websocket.html)
