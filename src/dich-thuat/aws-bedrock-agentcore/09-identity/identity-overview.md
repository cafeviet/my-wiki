# Tổng quan về Amazon Bedrock AgentCore Identity

Trong bối cảnh các agent (tác tử AI) đang tiến hóa nhanh chóng, các tổ chức cần những giải pháp quản lý danh tính (identity) vững chắc có thể xử lý các thách thức đặc thù gắn với các danh tính phi con người (non-human identity). Amazon Bedrock AgentCore Identity giải quyết những thách thức này bằng cách cung cấp một khả năng tập trung để quản lý danh tính agent, bảo mật credential, và cho phép tích hợp liền mạch với các dịch vụ AWS và bên thứ ba thông qua Sigv4, các luồng OAuth 2.0 chuẩn hóa và API key.

Dịch vụ này triển khai các cơ chế kiểm soát xác thực và ủy quyền, xác minh từng request một cách độc lập, yêu cầu xác minh tường minh cho mọi nỗ lực truy cập bất kể nguồn gốc. Nó tích hợp liền mạch với các dịch vụ AWS đồng thời cho phép các agent truy cập bảo mật vào các tool (công cụ) và dịch vụ bên ngoài. Dù bạn đang xây dựng các script tự động hóa đơn giản hay các hệ thống đa agent phức tạp, AgentCore Identity cung cấp nền tảng danh tính để giúp các ứng dụng của bạn vận hành bảo mật và hiệu quả.
