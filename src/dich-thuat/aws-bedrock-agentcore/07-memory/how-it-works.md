# Cách hoạt động

AgentCore Memory (bộ nhớ) cung cấp một tập hợp API cho phép các Agent (tác tử AI) của bạn lưu trữ, truy hồi, và tận dụng liền mạch cả bộ nhớ short-term lẫn long-term. Kiến trúc được thiết kế để tách bối cảnh tức thời của một cuộc trò chuyện khỏi tri thức bền vững cần được giữ lại theo thời gian.
